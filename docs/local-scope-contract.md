# Local Scope Contract

- Werkwoordlab is the local werkwoordspelling product.
- This repo owns the learner flow from grammar function to rule choice to spelling application.
- This repo owns local evaluator behavior, misconception mapping, unit progression, transfer tasks that remain subordinate to werkwoordspelling, and spelling-specific teacher insights.
- Canonical parsing runtime UI does not belong here.
- Shared didactic canon, shared taxonomy governance, shared sentence rules, and shared AI instruction layers do not belong here.
- Reusable cross-product artifacts move upward through grammar-core, not sideways through local product expansion.
- Automatic documentation sync may update only docs/auto-sync files unless a human task explicitly broadens scope.
- Werkwoordlab is not a general writing platform and should not silently grow into one.
